Pastebox

Simple file & text sharing via curl

Upload text

echo "Hello World" | curl -sS --data-binary @- {{ base_url }}

Upload file

curl -sS -F "file=@example.txt" {{ base_url }}

Password protected

curl -H "usepassword: true" --data-binary @- {{ base_url }}

Permanent storage

curl -H "data-policy: permanent" --data-binary @- {{ base_url }}

Pastes expire after 30 days by default

Each upload returns a delete URL for manual removal
